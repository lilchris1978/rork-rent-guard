RentGuard app

This app should make life easier for landlords and property managers.

Tenants send SMS messages describing their issues, and the AI in this app handles them automatically.

For example, a tenant sends an SMS saying, “Water leaking.” The AI identifies who the tenant is and which unit 
the issue is coming from, sets the priority level, contacts the most suitable vendor (such as a plumber), schedules 
an appointment, and informs the tenant via SMS when the plumber will arrive. The tenant can then confirm the appointment, 
and the landlord or property manager receives updates about the entire process.
